# 🐱 냥이 키우기

고양이를 돌보고, 산책하다 길냥이를 냥줍하고, 연애·출산으로 식구를 늘리고,
캣타워를 꾸미고, **냥이 마을에서 친구 집에 놀러 가는** 웹 고양이 라이프 시뮬레이션이에요.

서버가 필요 없어요. `index.html` 파일 하나로 돌아가고, 무료 정적 호스팅에 올리면 누구나 들어올 수 있어요.

## 기능

| 분류 | 내용 |
|---|---|
| 돌보기 | 밥 · 놀기 · 씻기 · 재우기, 욕구 5가지(배부름/즐거움/청결/기운/사교), 성격 6종 |
| 산책 | 걷다가 랜덤 이벤트 — 길냥이 냥줍, 츄르·코인 줍기, 강아지, 웅덩이 등 |
| 관계 | 인사 · 그루밍 · 같이 놀기 · 장난 · 고백 · 아기 갖기 · 헤어지기 |
| 출산 | 15초 임신, 1~3마리, 털색·무늬·눈색·성격 유전, 4분 뒤 어른 |
| 꾸미기 | 캣타워 부품·가구 12종, 드래그 배치, 위에 쌓으면 자동 스냅 |
| 마을 | 접속 중인 이웃 목록, 집 놀러가기, 실시간 말풍선·이모트, 방명록 |
| 저장 | 브라우저 자동 저장 + 백업 코드(다른 기기로 옮기기) |

## 웹사이트로 올리기 (무료)

### 방법 1. GitHub Pages — 오픈소스로 공개하기 (추천)
1. [github.com](https://github.com)에 가입하고 **New repository**를 눌러 `nyang-kiugi` 같은 이름으로 **Public** 저장소를 만들어요.
2. **Add file → Upload files**에서 이 폴더의 파일을 전부 끌어다 놓고 **Commit changes**.
3. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/nyang-kiugi/` 주소가 생겨요. 이 주소를 친구에게 보내면 끝!

### 방법 2. Netlify Drop — 가장 빠르게
1. [app.netlify.com/drop](https://app.netlify.com/drop)에 이 폴더를 통째로 끌어다 놓아요.
2. 생긴 주소를 계속 쓰려면 Netlify에 가입해서 사이트를 내 계정에 저장해요.

## 핸드폰에서 앱처럼 쓰기
- 아이폰(사파리): 공유 → **홈 화면에 추가**
- 안드로이드(크롬): ⋮ → **홈 화면에 추가**

## 마을(멀티플레이)은 어떻게 돌아가나요?
- [Trystero](https://github.com/dmotz/trystero)(MIT)로 브라우저끼리 **WebRTC로 직접 연결**해요. 연결 상대를 찾을 때만 공개 Nostr 릴레이를 써요. 우리 서버는 없어요.
- 그래서 **지금 접속해 있는 집에만** 놀러 갈 수 있어요.
- 방명록은 **집주인 기기에 저장**되고, 집주인이 접속해 있을 때 남길 수 있어요.
- 처음 연결까지 10~20초쯤 걸릴 수 있고, 회사·학교 네트워크에서는 WebRTC가 막혀 연결이 안 될 수도 있어요.
- 한 마을(로비)에 수십 명 정도까지가 쾌적해요. 사람이 아주 많아지면 방 나누기가 필요해요.
- 내 게임만의 마을을 따로 만들고 싶으면 `index.html`에서 `NET_APP` 값을 다른 문자열로 바꾸세요.

## ⚠️ 안전 안내
마을은 누구나 들어올 수 있는 공개 공간이고, 말풍선·방명록에 별도 필터가 없어요.
모르는 사람에게 이름·학교·연락처 같은 개인정보를 알려주지 마세요.

## 기여하기
누구나 환영해요! 저장소를 Fork → 수정 → Pull Request를 보내 주세요.
- 코드는 `index.html` 한 파일에 다 들어 있어요. 빌드 도구가 필요 없어요.
- `/* ===== ... ===== */` 주석으로 구역이 나뉘어 있어요: 데이터, 그리기, 돌보기, 관계, 출산, 산책, 캣타워, 저장, 마을.
- 로컬에서 테스트: 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.
- 아이디어: 캣타워 부품 추가, 산책 이벤트 추가, 미니게임, 계절 이벤트, 욕설 필터, 신고/차단 기능
